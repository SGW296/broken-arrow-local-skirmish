# Changelog

## 3.1.0-alpha.1 — first public lobby alpha

- Public fork with release-only installation, DLL integrity checks, backups and rollback instructions.
- Clearer active/closed roster presentation, match summary and army-mode guidance.
- Public-alpha version display and a focused graphical polish pass.
- Source build/check instructions and public managed-fixture CI.
- Compatibility explicitly limited to the tested v1.2.0 offline setup; no new AI behavior.

Includes the local 3.0.1 lobby foundation: native map-card previews and styling, 1v1–5v5/uneven team setup, closed slots, native AI profile selection, custom-deck choices, nation filters, saved configurations and read-only wave diagnostics. Normal is the label for native Medium (value 2).

- 3.0.0: runtime closed-slot support, native AI presets and the native-inspired roster layout; Airbase Hard 1v1 test.
- 2.8.0: team rosters and native map previews.

These local versions were developed from upstream 2.6.3. They are historical references, not alternative public installation candidates.
